## Quick Commands
```bash
# Start Vite development server with proxy to backend
pnpm dev

# Full TypeScript check + production bundle build
pnpm build

# Regenerate API client and React Query hooks from openapi.json
pnpm generate:api

# Preview built production distribution
pnpm preview
```
